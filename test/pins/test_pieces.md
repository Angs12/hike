# Pins: Cbat_clp.Pieces

Module `Cbat_clp.Pieces` (and the exact run list, `Cbat_clp.Exact`). One row per pin in
`test/unit/test_pieces.ml`.

Red evidence is recorded per row; where no observed failure is cited it is
by review. Historical disable recipes name the mechanism at introduction.
